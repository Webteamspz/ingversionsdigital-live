Setup Development Environment

Install these before touching the repo:

  • Node.js 20+ — the JS runtime Vite, npm, and every build script run on. Get it from nodejs.org (LTS build).
  • Git — for cloning the repo and working with the new-theme → stage → production branch flow. Get it from git-scm.com.
  • VS Code (or any editor) — the codebase uses plain JS/JSX + CSS Modules, no editor-specific tooling required. Get it from code.visualstudio.com.
  • npm — ships with Node, used for all scripts in this project (install, dev, build, lint).

Introduction

Clone the repo, install dependencies, run the dev server:

For npm:

git clone https://github.com/Webteamspz/ingversionsdigital-live.git
cd ingversionsdigital-live
npm install
npm run dev

Open http://localhost:5173 (Vite's default dev port).

Building for a target environment (mirrors what CI runs on push):

npm run build:staging      # mode=staging, gates the site behind StagingLogin
npm run build:production   # mode=production, the real public build

Copy .env.example to .env (or .env.staging / .env.production) before running a mode-specific build — see the env var list in the developer guide for what each key does.

Folder Structure

  • public/ — static assets served as-is (favicons, manifest, sitemap, robots.txt)
    • assets/ — images referenced by src/data/*.js (team photos, logos, icons)
  • src/
    • pages/ — one folder per route (Home, AboutUs, Pricing, Projects, TeamPage, Legal, NotFound)
    • components/ — presentational pieces, each folder holds a .jsx + a .module.css (Header, Footer, Hero, Pricing, Contact, CompanyLogos, ...)
    • data/ — all site copy as plain JS objects (sitedata.js, pricingdata.js, teamdata.js, projectsdata.js, aboutusdata.js, ...) — edit these, not the JSX, to change content
    • styles/style.css — global design tokens (colors, radii, shadows) as CSS custom properties
    • config/deploy.js — environment/deploy-related config
    • gtm.js — hand-rolled GTM/dataLayer analytics wrapper
    • App.jsx — route table (React Router v7)
    • main.jsx — app entry point
  • docs/ — DEVELOPER_GUIDE.md (full onboarding doc) and this documentation page
  • scripts/convert-images.mjs — resizes/converts images to .webp via sharp
  • Dockerfile, nginx.conf, docker-compose.*.yml — production/staging container build
  • DEPLOYMENT.md — Hostinger + GitHub Actions deploy setup
  • package.json — scripts and dependencies
  • node_modules/ — installed packages (gitignored)

Pages and Components Info

Routes, defined in src/App.jsx:

  • Home — / → src/pages/Home/Home.jsx
  • Team — /teampage → src/pages/TeamPage/TeamPage.jsx
  • About Us — /about-us → src/pages/AboutUs/AboutUs.jsx
  • Pricing — /pricing → src/pages/Pricing/Pricing.jsx
  • Projects — /projects → src/pages/Projects/Projects.jsx
  • Privacy Policy — /privacy-policy → src/pages/Legal/PrivacyPolicy.jsx
  • Terms of Service — /terms-of-service → src/pages/Legal/TermsOfService.jsx
  • 404 — any unmatched path → src/pages/NotFound/NotFound.jsx

Home is assembled from section components, each eager-imported (not lazy — see the developer guide for why): Hero, TrackRecord, Services, WorkProcess, EngagementModels, Reviews, WhyChooseUs, CompanyLogos, BlogSlider, FAQ, Contact.

Template Features

  • React 19 + Vite 7, plain JS/JSX (no TypeScript)
  • React Router v7 (BrowserRouter)
  • CSS Modules for styling — no Tailwind, no CSS-in-JS
  • Data-driven content — all copy lives in src/data/*.js
  • react-helmet-async for per-page SEO tags
  • lucide-react icon set
  • Swiper.js for carousels (team, blog, reviews)
  • Formspree-backed contact form
  • Client-side staging login gate (review speed-bump, not a security boundary)

Fonts

Two Google Fonts load by default — Outfit (headings, weights 600/700/800) and Plus Jakarta Sans (body/UI, weights 400-700). Both are pulled in index.html, not per-component: 

<link href="https://fonts.googleapis.com/css2?family=Outfit:wght@600;700;800&family=Plus+Jakarta+Sans:wght@400;500;600;700&display=swap" rel="stylesheet" />

To change the font: edit that one <link> in index.html, then update the font-family declarations in src/styles/style.css and each component's .module.css (search for "Plus Jakarta Sans").

Icons

Icons come from lucide-react. Browse the set on the Lucide site, then import the matching component: 

import { ArrowUp } from "lucide-react";

<ArrowUp size={20} color="var(--palette-border)" />

Deploy

This project does not deploy via FTP upload — it ships as a Docker image behind nginx, deployed to Hostinger through GitHub Actions. The flow:

  1. Work happens on new-theme.
  2. Merge/cherry-pick into stage → pushing it triggers .github/workflows/deploy.yml, which builds the Docker image and deploys the staging container.
  3. Once verified on staging, merge stage into production (PR, since this repo doesn't use the gh CLI) → pushing triggers the production deploy the same way.

To produce a static build locally (for inspection, not for manual upload):

npm run build:production

Outputs to dist/. Full infra details (Docker, Hostinger API, GitHub Actions secrets, nginx CSP) live in DEPLOYMENT.md at the repo root.
